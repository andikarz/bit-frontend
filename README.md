# bit-frontend

Frontend application for the Beasiswa Pelatihan platform built with React, TypeScript, Vite, and Bootstrap 5.3.3.

## Features
- Calon Pendaftar portal:
  - Homepage catalog & program details modal (1_index.html)
  - 4-step registration wizard with auto-save & resume (2_index_awal.html)
  - Submitted read-only view with status ticket (3_index_terkirim.html)
  - Revision form with verifier notes (4_index_revisi.html)
  - Program closed / announcement view (5_index_ditutup.html)
  - Acceptance letter & confirmation view (6_index_lulus.html)
- Internal portal:
  - Internal login (Internal/1_index_login.html)
  - Verifikator review workspace (Internal/2_index_verifikator.html)
  - Interview scoring sheet (Internal/3_index_wawancara.html)
  - Admin dashboard & master management (Internal/4_index_admin.html)

## Scripts
- `npm run dev`: Start Vite development server
- `npm run build`: Build production bundle
- `npm start`: Run Node static production server on port 3000
